
# Pokédex CLI

Because catching Pokémon in your terminal is way cooler than scrolling TikTok.

Pokédex CLI is a simple terminal-based adventure where you explore locations, encounter wild Pokémon, and catch them — all powered by [PokéAPI](https://pokeapi.co/). It’s basically like playing Pokémon Red if Game Freak had only given you a keyboard and zero graphics.

---

✨ **What’s This?**
- Explore maps and move, but Command-only.
- Encounter random Pokémon in the wild and try to catch them.
- Inspect Pokémon stats (straight from PokéAPI).
- Build your own little Pokédex collection.
- All inside your terminal. No Game Boy required.

---

⚠️ **Heads Up**
- This is just a toy project. Don’t expect full Pokémon battles, animations, or Professor Oak yelling at you.
- All data comes from PokéAPI — if that goes down, blame them, not me.
- Think of this as Pokémon-lite for nerds who like typing.

---

🛠 **Installation**
```bash
git clone https://github.com/sithusan/pokedex-cli.git
cd pokedex-cli
npm install
npm run start
``` 

# Example Session

**Pokedex > map**
1. Pallet Town  
2. Viridian City  
...

**Pokedex > explore pallet-town**  
_A wild Pikachu appeared!_

**Pokedex > catch pikachu**  
_You caught Pikachu! 🎉_

**Pokedex > pokedex**  
- Pikachu (Electric)

## 🧠 Why This Exists
Honestly? Just for fun. I wanted to practice building a CLI app in TypeScript and figured Pokémon would be more fun than making yet another TODO app.  

If you’re learning Node.js, readline, or just want to hack around with APIs, this is a good little playground.
